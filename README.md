# Marine Map

Non-native marine species, species that establish populations outside their historical range, have become a major ecological and economic concern in coastal ecosystems. The Marine Map website seeks to allow users to explore marine species data in an interactive map, with filtering capabilities for species, year, and dataset. This project is being developed with Carolina Bastidas at the MIT Sea Grant and is designed to support researchers in visualizing distributions of introduced marine species off the coast of New England.

### Features: 

* **Timeline**: Users can go through years or select all years to examine spatial distributions during different timeframes.

* **Pop-ups**: When users click on a species’ record point, a detailed pop-up window appears with information about the site and source if available.

* **Customizable data layers**: Researchers can select which datasets to display, choosing between the rigorously verified RAS and NEMESIS records or the more comprehensive but less standardized OBIS data.

* **Two-species comparison**: Users are able to select the Multi-species comparison tab and view data from two different species at the same time.


## Deployment
This website is deployed with [Vercel](https://vercel.com/) on the free plan. The current deployment is at [marine-map.vercel.app](https://marine-map.vercel.app/). 

## Required Installation
* JavaScript
* Node.js
* React
* PapaParse

## Usage
### To start a local dev server for the project:
In the command prompt, locate the project folder and type ```npm install``` to install dependencies. After the installation, type ```npm run dev``` and navigate to the ```localhost``` link provided.
